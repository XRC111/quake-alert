## 新建项目：QuakeAlert 跨平台地震预警客户端（KMP + Compose Multiplatform）

在工作区 `D:\ai_workbuddy\earthquake` 从零生成完整工程骨架（41 个文件，未执行编译，因为本地无 Android SDK/Xcode，需在 CI 或配好环境后验证）。

**技术栈**：Kotlin 2.1.20 + Compose Multiplatform 1.8.0 + AGP 8.7.3 + Gradle 8.11.1（wrapper 已本地生成并复制进项目）+ Ktor 3.1.0（WebSockets）+ kotlinx-serialization/datetime/coroutines + JetBrains lifecycle-viewmodel-compose 2.8.7。JDK 17 toolchain。

**架构要点**：
- `QuakeAggregator`（commonMain）：Wolfx `wss://ws-api.wolfx.jp/cenc_eew` WebSocket + USGS `all_hour.geojson` 每 30s 轮询，双源 SupervisorJob 隔离、指数退避+抖动重试、WS 心跳看门狗（90s 无帧主动断开）；输出 `events: SharedFlow`（增量）+ `history: StateFlow`（快照≤50 条，同 ID 就地覆盖）；USGS seenId 3h TTL 去重。
- `AlertTrigger` 接口 + `DefaultAlertTrigger`：Wolfx≥M3.0 / USGS≥M5.0 且深<50km；30 分钟窗口去重（可配置 `allowEscalationReAlert` 允许震级上调≥0.5 复报）；倒计时用走时差模型 `distance*(1/3.5-1/6.0)-elapsed`（近似值，README 已注明）。
- Wolfx 解码器为**宽容 JsonElement 读取**（字段别名兜底 + heartbeat 过滤 + 三种时间格式），刻意不用 @Serializable 硬绑，防上游字段漂移。
- expect/actual：`AlertEffects`（声音/震动/亮屏/通知/置顶，全部 runCatching 兜底不抛异常）+ `PlatformLocation`（Android lastKnownLocation；iOS/Desktop 默认 null，Desktop 支持 `-Dquake.observer.lat/lon`）。
- UI：Material 3 深色主题，`LazyColumn` 列表 + 全屏红色闪烁 `Dialog`（dismissOnBackPress/ClickOutside=false，仅"我已安全"可关）。

**CI**：`.github/workflows/build.yml` — macos-latest 出 APK/AAB + iOS XCFramework + DMG；windows-latest 出 Msi/Exe；签名走 Secrets（KEYSTORE_BASE64 等），未配置时回退 debug 签名；打 v* tag 自动发 Release。
